Welcome to the Game III Assistant

JEDKX WTTG3 Assistant is a compact helper for Welcome to the Game III runs. It keeps WTTG3 website uptime, Otrex clickpoint guide links, VirtMesh PC rates, wiki route filters, key notes, and fetch file findings in one static console.

Use it as a WTTG3 operator console when checking site availability, matching a website to its clickpoint guide, comparing VirtMesh mining choices, or scanning pasted page source for key and fetch patterns.

JEDKX

Operator Notes

Console

Use the left panel as the live route map. Always-open sites stay on the left; timed sites stay grouped on the right.

Viewer

main is the first page. Names like submit, catalog, order, or page2 are mapped subpages in the Otrex guide set.

Open Icon

The icon beside the selected website opens the current Otrex page externally and leaves this console in uptime/miner mode.

VirtMesh

Tier buttons filter hosts by availability tier. Rates are sorted high to low inside each tier.

Otrex Guide Pages

The right-side viewer opens the matching Otrex clickpoint page for the selected website. Use the marked areas and labels shown on that embedded page to find the key click location.
